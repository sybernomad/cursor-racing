# Credits & Third-Party Notices

## Third-party code and assets

**None.** Cursor Racing ships with zero third-party dependencies:

| Area | How it's made | License impact |
|------|---------------|----------------|
| Code | Hand-written vanilla JavaScript, HTML and CSS | Covered by this project's MIT `LICENSE` |
| 3D graphics | WebGL 2 renderer written for this game; cars and props are voxel models generated in code (`js/models.js`) | Original work |
| Pixel sprites | Drawn from character maps in `js/models.js` | Original work |
| Table textures | Painted at runtime on `<canvas>` (`js/tracks.js`, `js/world.js`) | Original work |
| Audio + music | Synthesized live with the Web Audio API (no audio files) | Original work |
| Icons | Pixel art generated by `tools/make-icons.py` | Original work |
| Fonts | The device's built-in system fonts; no font files are bundled | Nothing to credit |

If you add a library, font, sound or image later, add its name, author, source URL and license here.

## Inspiration

Inspired by classic top-down toy-car racing games and by pixel art shown in a lit 3D diorama
with tilt-shift depth of field. Cursor Racing is not affiliated with, endorsed
by, or connected to any of them. All trademarks are the property of their respective owners.
No names, logos, art, music or sound from those works are used.
